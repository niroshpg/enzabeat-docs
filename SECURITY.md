# Security

## Reporting a vulnerability

Report it privately through GitHub: [open a private security advisory](https://github.com/niroshpg/enzabeat-docs/security/advisories/new) on this repository. Please do not open a public issue for a suspected vulnerability.

Include what you found, how to reproduce it, and what an attacker could do with it. You will get an acknowledgement, and a fix or an explanation, before anything is disclosed publicly.

## Scope

- The Enzabeat iOS and Android apps and the session host, as they become available.
- The enzabeat.com site.
- Weaknesses in the design described in this repository. If a promise in the [README](README.md) does not hold as described (for example, if audio could leave a phone), that is in scope even without a working exploit.

Enzabeat is in design and has no released app, so most of the design above has no running surface yet.
